# swiss_knight

A terminal-based chess tournament manager designed for running events with the Swiss system.

## Overview

`swiss_knight` provides an interactive terminal interface to manage tournaments from start to finish:

1. **Player Registration**: Enroll and manage participants in the tournament lobby.
2. **Swiss Pairings**: Generate round-by-round pairings dynamically based on player scores and match histories from previous rounds.
3. **Round Results**: Record match outcomes and compute updated standings across each round.
